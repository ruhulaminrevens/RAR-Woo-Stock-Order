# RAR Woo Stock & Order v1.3.0 — Checkpoint 1

Status: **Development checkpoint — not a production release**

Baseline: **v1.2.1**

Reference: approved Claude dashboard prototype / patch. The prototype is treated as a UI/feature reference only; v1.2.1 fixes and WooCommerce compatibility remain authoritative.

## Completed in this checkpoint

### Dashboard/API foundation
- Dedicated `RAR_WSO_Reports` read-only reporting service.
- Role-aware dashboard payload: `staff` vs `manager`.
- Dashboard periods: Today, 7 days, This month.
- Manager report periods: 7, 30, 90 days.
- Current-vs-previous-period order and sales comparison.
- 7-day sales/order trend payload.
- Recent-order feed.
- Needs Attention feed.
- Manager Order Control totals.

### Inventory semantics
- Healthy: managed stock >= 11.
- Low: managed stock 1–10.
- Out: zero quantity / out-of-stock.
- Not tracked: WooCommerce stock management disabled.
- Available / Live counts only positive managed stock.
- Not tracked stock remains separate.
- Units in hand and estimated stock value included in dashboard data.

### Role-aware UI
- New dark operations dashboard.
- Staff dashboard: order KPIs, inventory, quick actions, 7-day sales, attention items, own recent orders.
- Shop Manager dashboard: all Staff sections plus Order Control and Sales & Growth.
- All Orders / Live Orders / Processing drilldowns.
- Today / 7 days / This month dashboard switch.
- 7 / 30 / 90 day manager reporting switch.
- Responsive desktop/mobile layout.

### Stability fixes
- Preserved v1.2.1 custom WooCommerce order-status normalization.
- Added Processing manager order mode.
- Fixed manager dashboard button binding to all `data-orders-mode` controls.
- Removed shipped HTML entity leakage in dashboard JavaScript.
- Staff recent-order feed avoids datastore-specific `meta_query` and works across legacy CPT and HPOS order stores.

## Preserved from v1.2.1
